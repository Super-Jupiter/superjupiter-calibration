# Security

Report suspected security vulnerabilities privately to **info@superjupiter.net**
with the subject `Security: SuperJupiter Calibration`. Include a minimal
reproduction and affected version. Please avoid publishing exploit details before
we have had an opportunity to assess the report. No response-time guarantee or
bug-bounty programme is offered.

This library has no networking, filesystem access, credentials, telemetry or
dynamic memory allocation. Applications remain responsible for input provenance,
thread synchronisation, logging, transport security and physical safeguards.
Quality flags do not authenticate data and are not a safety certification.
